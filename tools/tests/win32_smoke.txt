# Shell commands driven into the booted kernel by tools/qemu_test.py.
# One per line; blank lines and comments are skipped.
#
# The order matters a little: peinfo before run, so a failure in the
# loader shows up as a header/import report before it shows up as a
# crash, and hellowin last so the transcript ends on the case that
# exercises the most of the emulation layer.

# vmtest first: it is not a Win32 case, but it exercises the paging
# machinery everything below stands on, and running it before and after
# the programs catches an address space that leaks frames.
vmtest
meminfo

peinfo hellowin.exe
run winapi.exe
run cppinit.exe
run guiapp.exe
run hello64.exe
run lowbase.exe
run hellope.exe
run crash.exe
run qsorttest.exe
run threads.exe
run hellowin.exe

# The non-PE paths through process.c, which Milestone 15 moved into
# private address spaces, and the two scheduler demos Milestone 16 added:
# multitask is three tasks in three address spaces at one address,
# threadtest is two threads in one address space sharing one counter.
run helloelf.elf
run helloc.bin
run posixtest.elf
run sigtest.elf
run pthtest.elf
run glibc.elf
run dyn.elf
run crashelf.elf
multitask
